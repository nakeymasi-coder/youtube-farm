How the YouTube farm works

The farm takes a run from a proven YouTube topic — and a Pinterest outfit or product when the video needs one — to a finished YouTube video, and brings the video back to you in chat for approval. One dashboard holds it all: the full Video Intake Form, the Character Vault for locked characters, solo forms for all 5 agents, and the Queue for every run and solo job.

YouTube difference: Long-form videos are built 16:9 for watch pages. YouTube Shorts are built 9:16. Character references stay 9:16 either way — headshots and body reference sheets are portrait locks. Thumbnails are 16:9 (1280 × 720).

The 5 agents, in order

1. Research Scout

Searches YouTube for proven topics, titles, hooks and angles in the chosen mode, and Pinterest for outfits and products — especially products available on Amazon. Works from guest view, no sign-in needed, just looking. Looks for outfits/products with an Amazon affiliate link. Does not go to Amazon to check price or availability at this step, and does not copy another creator's video — it reports the angle, not a rip.

2. Image Agent

Creates the person and avatar images. Ultra realistic, real skin texture and real hair texture. Creates the character references, the outfit reference and the outfit reference sheet — all in chat, all PNG, all 9:16 — plus the 16:9 YouTube thumbnail image, also PNG.

3. Story & Script Agent

Writes the first-30-seconds hook, the full spoken script, chapter breaks and the shot list. Labels every scene with the run's one Product Presentation choice. Writes scene action only for VideoExpress prompts, never a description of the character.

4. VideoExpress Agent

Makes the video in VideoExpress at app.videoexpress.ai using the Consistent Character workflow below. Long-form scenes are composed 16:9, Shorts scenes 9:16, always from the same two references. Returns the finished video in chat for approval. Never posts or publishes it.

5. Title, Description & SEO Agent

The YouTube version of the Caption Agent. Writes the click-worthy title (honest, no false claims), the full description, chapters / timestamps, tags, hashtags, a pinned comment and an end-screen / next-video line — plus a Shorts caption if the video is cut down. No price, discount or sale claim unless a live price was actually verified.

The Product Presentation rule — either / or, never both

Every run picks one single choice, right after Mode: Wearing the product or Holding the product.

Wearing run — every prompt ends: Wearing the product, not holding it.
Holding run — every prompt ends: Holding the product, not wearing it.

Never wearing an outfit while holding that same outfit on a hanger. Reject and regenerate any image that shows both. If a video needs both, holding first and wearing later — use separate scenes, never the same shot.

The thumbnail rule

One thumbnail per long-form video: the locked character's real face from her references, 3–4 big words max, readable on a phone, no tiny text, no face that isn't hers. The thumbnail is made in chat as a 16:9 PNG and returned with the video for your approval — never uploaded without it.

How Run in Chat works

Every Queue run gets a Run in Chat button. Pressing it sets that run to working and opens a Run in Chat card showing the locked character, Slot 1 headshot and Slot 2 single 9:16 body reference sheet status and location with thumbnails when uploaded, the voice, the mode, the Product Presentation choice and its exact prompt sentence, the YouTube format, the topic, the length, the product name and link, and the reference video link when present. The card has a Copy prompt button. You paste that prompt into a new chat and Muse runs that exact run — nothing swapped. There is no scheduled pickup. Do not build one unless asked for separately.

The workflow, step by step

  1. Pick the angle — and the outfit/product when there is one. Research Scout finds a proven YouTube angle for the mode and topic, and the Pinterest outfit/product with an Amazon affiliate link. Copy its picture.
  2. Lock the outfit in chat, not in VideoExpress. Using the locked character's reference photos, put that character in that exact outfit in chat first. Check it for face match and outfit match.
  3. Make the outfit reference sheet in chat. From that approved outfit photo, create one single 9:16 reference sheet with front, profile and three-quarter shots of her in that outfit, all on the same photo. Save it as PNG.
  4. Upload to VideoExpress. Slot 1 is her headshot. Slot 2 is that chat-made outfit reference sheet. Never leave Slot 2 empty.
  5. Create scenes from that headshot plus sheet lock, in script order — 16:9 for long-form, 9:16 for Shorts.
  6. Make the thumbnail in chat — 16:9 PNG, her face, 3–4 big words.
  7. Export and return the video + thumbnail in chat for approval. Do not post, publish or share it.

VideoExpress — Consistent Character, every time

  1. Create with AI, go to the first option and click Consistent Character, then use Consistent Character Reference.
  2. Reference One: headshot. Reference Two: the chat-made outfit reference sheet.
  3. Make sure Consistent Character is selected, then create image.
  4. No character bible is needed. The reference photos are the lock. Do not paste a bible into the scene prompts.

Use this prompt shape for every scene — and nothing else about her

Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it.

Never describe her in the prompt. No face, hair, skin, body or outfit description. Describing her overrides the references and creates a different girl. The last line swaps to the holding version when that is the run's choice.

Standing rules

Image format: Every image Muse creates must be PNG, not webp — character images, outfit references, outfit reference sheets and thumbnails. Your own uploaded Vault photos stay as you saved them, JPG or PNG. Webp uploads are rejected with a clear message.

Characters: Ultra realistic, with real skin texture and real hair texture. Character A is reused as Character A, Character B as Character B. Within one video, identity, clothing, location and lighting stay frozen from the uploaded reference photos.

Permissions: Standing upload permission for VideoExpress — Muse has full permission to upload to VideoExpress for farm runs without stopping to ask each time. That covers headshots, body reference sheets, chat-made outfit references, outfit reference sheets and scene files. That permission does not cover posting or publishing to YouTube. Those still need your separate approval. Sign-in screens and Terms screens still pause for you.

Billing: VideoExpress billing is usage based, not credits. Do not pause a run for credits. Keep going.

Queue rule: The Queue status button only changes the label to queued, working or done. It does not run YouTube/Pinterest research, image generation or VideoExpress. Real execution is triggered from chat, using Run in Chat.
